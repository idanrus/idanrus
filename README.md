## Проекты

**Аналитика**

- [olist-analytics](https://github.com/idanrus/olist-analytics): анализ бразильского маркетплейса на 99 тыс. заказов. Метрики по месяцам, когорты и retention, доставка и отзывы, RFM-сегментация. SQL + Python, [дашборд в DataLens](https://datalens.yandex/gt2bsobh6bjaz)

**Deep Learning**

- [gesture-classification-cnn](https://github.com/idanrus/gesture-classification-cnn): классификация жестов на фото, от своей LeNet-5 до дообучения resnet18 и efficientnet_b0, аугментации, MixUp, CutMix, TTA
- [char-rnn-names](https://github.com/idanrus/char-rnn-names): ячейки RNN, GRU и LSTM вручную на PyTorch, генерация имён и определение пола по имени

**Классический ML**

- [tree-ensembles-from-scratch](https://github.com/idanrus/tree-ensembles-from-scratch): дерево решений, Random Forest и градиентный бустинг с нуля, сравнение с LightGBM, XGBoost и CatBoost
- [lemon-cars-classification](https://github.com/idanrus/lemon-cars-classification): логистическая регрессия, Naive Bayes, KNN и метрики классификации с нуля на данных автоаукциона
- [model-validation-from-scratch](https://github.com/idanrus/model-validation-from-scratch): схемы кросс-валидации, отбор признаков и подбор гиперпараметров с нуля, какая валидация честнее всего
- [linear-models-from-scratch](https://github.com/idanrus/linear-models-from-scratch): линейная регрессия, Ridge, Lasso и ElasticNet на NumPy с SGD
- [clustering-rent-prices](https://github.com/idanrus/clustering-rent-prices): свой K-means, DBSCAN, GMM, кластеры по координатам как признак для цены аренды
- [unsupervised-dimensionality-reduction](https://github.com/idanrus/unsupervised-dimensionality-reduction): PCA, SVD, t-SNE, UMAP на MNIST, сжатие картинок и отделение фона на видео
